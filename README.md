### 🧪 Автотестирование

- **UI-тесты** — Playwright + pytest: формы, меню, сценарии пользователя, разные браузеры и экраны.
- **API-тесты** — requests / HTTPX: статусы, схемы ответов, авторизация, негативные проверки.
- **CI/CD** — тесты запускаются сами на каждое изменение в GitHub Actions.
- **Allure-отчёты** — понятный отчёт с шагами и скриншотами, итог прогона приходит в Telegram.

### 🌐 Сайты

- Визитки, лендинги и многостраничные сайты: адаптивные, быстрые, с формой заявки.
- SEO-настройка и аналитика — сайт должен приводить клиентов, а не просто работать.
- Каждый сайт до сдачи проходит автотесты.

### ⚙️ Как я проверяю

```
изменение в коде → GitHub Actions → pytest + Playwright + API-тесты → Allure-отчёт → итог в Telegram
```
